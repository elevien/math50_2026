# Math 50

All material and [course page](https://elevien.github.io/math50_2026/) for Math 50, a linear regression modeling course at Dartmouth.

This is the private authoring repo. The public course page and any material that's been released so far live in [elevien/math50_2026](https://github.com/elevien/math50_2026), kept in sync via `tools/sync_public.sh` (see `publish-manifest.txt` for what's currently public).
